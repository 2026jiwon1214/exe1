# 🗓️ 데일리로그 (DailyLog)

> **달력 기반의 미니멀 일기(Diary) & 시간별 일정(To-Do) 웹 애플리케이션**  
> 모던한 흑백 베이스에 청량한 스카이블루 포인트를 더한 감성적인 개인 라이프로그 도구입니다.

---

## ✨ 주요 기능

### 1. 📅 한눈에 보는 월별 캘린더
- **오늘 날짜 강조**: 스카이블루 원형 하이라이트로 오늘을 한눈에 식별
- **시각적 인디케이터**:
  - `🕒 14:00 미팅`: 시간이 지정된 일정을 달력 셀에서 바로 확인
  - `☑️ N건 남음`: 남은 할 일 수 뱃지 표시
  - `📝 일기` / `오늘의 기분 이모지`: 일기가 기록된 날을 직관적으로 확인

### 2. 📝 오늘의 일기 & 자동 메타데이터
- **자동 정보 수집 (API 키 불필요)**:
  - ⏰ **작성 시간**: 현재 시각 자동 입력
  - 🌤️ **실시간 날씨 & 기온**: Open-Meteo 기반 현재 기온 및 날씨 상태 자동 감지
  - 📍 **장소**: 브라우저 GPS + 오픈 역지오코딩 기반 거주 지명(시/구 단위) 자동 입력
  - *모든 자동 입력값은 언제든 클릭하여 수동 수정 가능*
- **오늘의 기분 태그**: 6가지 감정 이모지 원클릭 선택

### 3. 🕒 똑똑한 날짜별 To-Do & 시간 관리
- **미래 날짜 보호**: 오늘 이후의 미래 날짜에는 일기 작성을 숨기고 오직 예정된 **할 일(To-Do)**에만 집중할 수 있도록 분리
- **일정 시간(Time) 지정**: 약속/미팅 시간을 설정하면 타임라인 순으로 자동 정렬
- **체크박스 & 삭제**: 간편한 완료(취소선) 토글 및 즉시 저장

### 4. ✈️ 여러 날짜를 아우르는 여행 / 기간 일정
- **기간 배너 표시**: 며칠에 걸친 여행, 휴가, 출장 일정을 달력 위에 깔끔한 띠 배너로 시각화
- **🎨 나만의 커스텀 테마 생성**:
  - 원하는 이모지 아이콘 직접 입력 (예: 🎵 콘서트, 🏔️ 등산, 💖 데이트 등)
  - 8가지 파스텔 컬러 팔레트 선택
  - 추가한 커스텀 테마 영구 보존 및 삭제 기능

### 5. 💾 안전한 데이터 저장 및 백업
- **오프라인 동작**: 서버 없이 브라우저 `localStorage`에 자동 영구 저장
- **백업 & 복원**: 상단 `[💾 백업]` 버튼으로 `.json` 파일 다운로드 및 `[📂 복원]` 지원

---

## 🚀 실행 방법

별도의 설치나 웹 서버 실행 없이 사용 가능합니다:
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등의 웹 브라우저에서 실행합니다.

---

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **APIs**:
  - [Open-Meteo Forecast API](https://open-meteo.com/) (무료 날씨/기온 조회)
  - [BigDataCloud Reverse Geocoding API](https://www.bigdatacloud.com/) (행정구역 지명 변환)
  - Browser Geolocation API
- **Storage**: Browser LocalStorage
- **Typography**: [Pretendard](https://github.com/orioncactus/pretendard)
